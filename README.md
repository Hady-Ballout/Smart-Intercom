# Interphone project

ESP32 door-entry prototype with QR visitor access, a resident web app, a Supabase backend, and device firmware.

- [Software, firmware, and setup instructions](interphone/README.md)

Hardware design and reproduction files are kept locally and excluded from version control. Hardware operation has been verified; cloud-to-hardware integration and video/audio calling remain to be completed.

Local credentials, dependency folders, generated builds, and the discard folder are excluded from version control. Copy the supplied example configuration files when setting up a new machine.
